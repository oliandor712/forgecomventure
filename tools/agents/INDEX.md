# MASTER INDEX: read this first, then jump to the files for your task

Paths are repo-relative. This file only points; it holds no rules. If a file here is missing, `git log --stat -- <path>` or `grep -r` for the name. Update this index in place when files move.

## 1. How to use
1. Tier 0 (always, about 3k tokens): `CLAUDE.md` and this index. Nothing else is loaded by default.
2. Tier 1 (by task): the section below plus only the matching `human_logic.toon` rows (`python3 tools/agents/lookup.py rule --area <area>`; areas: curve, data, power, builder, commanders, starters, testing, pc-npc, tags, pool, ai). Then that section's handoff.
3. Tier 2 (only when the task needs it): `MAIN_SESSION_BRIEF.md`, `CONTEXT.md`, `TOOLBOX.md`, long design docs.
4. Never read a file marked BIG whole. Use the slice command. Otherwise Grep first, then Read with offset/limit.
5. Generated files (`STARTER_TAGS.toon`, `TAG_REFERENCE.md`, `ABILITY_TWINS.json`, `TOOLBOX.md`) are regenerated by their scripts, never hand-merged.
6. Push rules: documents via `python3 tools/agents/docpush.py <paths> -m msg`; everything else only on the user's "push". No force-push, no PRs.

**Do not search or read `tools/concordia/backups/`** (540 text files, ~490k tokens, copies of live files; written as pre-change backups, not for lookup). Search with `grep -r ... --exclude-dir=backups`, or `rg -g '!backups'`; open a backup only when a task is a rollback or a diff against it (its `README.txt` first). Also skip `ai_lab/digests/` and `ai_lab/results/` (raw run output).
