# Starter tagging run: sample set (3 per card type, 1 per supertype)

Generated by `deckgen/tag_run.py starter`. Oracle text is the `Oracle:` line of the Forge script (`/` = line break). Tags: supertype, cardtype, subtype, keyword and qualifiers, ability tags. Groups: tags on the same script line are linked (k = K: line, c = A/S/T/R line, c0 = card level). Cards marked (not in starter decks) come from the whole card pool.

Tag notes: `put_onto_battlefield` (with `put_from:<zone>`) = a card put onto the battlefield without being cast, so its mana cost and cast triggers are skipped; enter-the-battlefield triggers still happen (CR 603.6a); it is separate from `trigger:etb`. `tempo:+n` = cards added to your hand or battlefield minus cards removed when the ability resolves (the spell itself, sacrificed and discarded cards).
