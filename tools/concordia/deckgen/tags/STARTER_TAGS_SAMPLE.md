Generated by `deckgen/tag_run.py starter` (revised in place each run). Sources: card script (1st), mtgish (2nd), Oracle text, Comprehensive Rules and the keyword reference, Forge AI `AILogic$` (reference). Cards are chosen from the starter decks and exclude the 27 cards of the first sample (you gave feedback on those: `TAG_FEEDBACK_STARTER_SAMPLE.md`). For each type: the card with the most ability families, a middle one, and one the cross-check changed or flagged.

**How to read:** *Oracle text* is the printed text (`/` = line break). *Tags* run supertype, cardtype, subtype/landtype, keyword and qualifiers, ability tags. *Linked groups*: tags of one script line (k = K: line, c = A/S/T/R line and its sub-steps, c0 = card level, v = added by the cross-check). *Cross-check*: `added` = tags the second sources (mtgish and Oracle both) supported and the script tags lacked, with their sources; `flag` = one source disagrees (not added, needs your word); `AI` = AILogic value. *Your note*: type your feedback in the last column (right / missing / extra tag, and what).
