## Reading of the baseline (Claude 2, 2026-10-22)
- **Already inside the plan's targets:** V4 score spread 0.008 (target <= 0.010), V2 text F1 0.983 (>= 0.95), accuracy 0.931 (guard >= 0.916). Reader scores are stable; what varies is wording and structure, which the score does not see.
- **Far from target:** V1 exact agreement 61.5% (>= 85%), V3 signature agreement 73.6% (>= 98%), S1b self-reference 61.3%. S1 (structure) is 95.3% (>= 98%): the linter's main complaints are reminder text and missing final periods; see the list above.
- **What actually differs between readers** (from the lowest-agreement cards):
  1. Zone-move verb: "Return ... to the battlefield" / "Put ... onto the battlefield" / dropped "under your control" for the same `put_onto_battlefield` + `from_zone:graveyard` + `controller` tags (Zombify). The `put_onto_battlefield`, `controller`, `from_zone` and `return` families sit at 42 to 52% disagreement.
  2. Variables: "deals damage equal to its power" vs "X damage, where X is its power" (Spikeshot Goblin); `x_is` definitions still written two ways.
  3. Placeholders: `{cost}` kept, `{Player}` / `{Its controller}` / `{Creatures}` capitalised in braces, `{If this spell was kicked, X is larger.}` as a bracketed note (Vines, Feed the Swarm, Propaganda).
  4. Ability-word conditions: "As long as delirium" vs "Delirium - ..." vs "as long as the delirium condition is met" (Dragon's Rage Channeler).
  5. Scope wording: "creatures can't attack" vs "can't attack you" (Ghostly Prison, Propaganda) when `restrict` has no scope value.
  6. Every family that reads as a list item (`scry`, `tutor_*`, `shuffle`, `discard`, `modal`, `num`) disagrees on about half its cards: mostly ordering and sentence splitting.
- **Caveats on the measure:** V3 compares (kind, trigger words, cost words, concept set); a one-word difference in the concept set breaks it, so V3 is stricter than a human would be. The 25-family table counts every family present on a disagreeing card, so families that co-occur (tutor_*) share the same cards. First-version parser, not hand-validated (phase 6).
- **Feeds phase 2:** the phrase book should fix, in this order: zone moves (put onto / return, controller), X and variable definitions, placeholder spelling (`{cost}`, `N`, `X`, never capitalised braces), ability-word conditions, scope on `restrict`, list-like families.
